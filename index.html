2P 使用小键盘，请开启 Num Lock。触屏使用屏幕按键。

J → J → J → K 轻击接重击；命中后可提前衔接，空挥需等收招。
W + K → E → J 挑空、E 爆冲追击、空中攻击；爆冲消耗 12 元气，最远 10 米。
S + K 下段扫腿；用 C + L 防御。
O / 受投时 O 近身投技突破格挡；被投时及时按 O 拆投。
L / 及时按 L 按住格挡；精准格挡可获得反击机会。
Q 残像：15 气，最多 2 次；每 6.5 秒恢复 1 次，冷却 1 秒。
受击时 L + Shift 爆气解围：35 气，冷却 5.5 秒。
命中后 Shift 消耗 8 气取消后摇，调整站位。
C / C + L 下蹲避高段，下段防御挡扫腿；无法抵挡空中攻击。
I / U 聚气起势 0.25 秒，每秒恢复 15 气；站定且受击打断。满气必杀，必杀在发动时消耗 100 资源。
F / 2P 小键盘 − 按下发射对应气弹或装备；牛魔王、乌龙、猫仙人没有远程攻击。克林蓄力气功使用 S+R。
Space / 2P 小键盘 0 悟空使用筋斗云；天津饭、饺子、比克大魔王可短时舞空，其余角色跳跃。
R / 2P 小键盘 + 主技能 R；第二技能 S+R（2P ↓+小键盘+）。费用、条件、独立冷却见角色指南。
自由练习 / T 切换陪练、查看判定与帧数；T 重置。
对战规则

99 秒，三局两胜；时间结束按剩余生命比例判胜。连击伤害递减；连续 6 次或空中 3 次受击触发击飞保护，落地造成破坏。

仙豆恢复 15% 生命：开战 25 秒、60 秒各刷新一次；场上最多一颗，12 秒未拾取则消失。满血不会消耗仙豆。

仙豆争夺模式有仙豆刷新；标准竞技不刷新仙豆。可在对战设置中切换。

开启出界判负后，仅武道会擂台生效；自由练习不判胜负。
