## 防止再次积累

ESLint 新增未使用变量与函数检查。模块接口文档由实际源码生成，`npm run architecture:update` 更新，`npm run architecture:check` 验证源码与文档一致；该检查已纳入本地验证与持续集成。

`npm run clean` 删除网站与离线构建、测试报告及本地构建缓存。再次开发或交付时重新构建即可；依赖安装与部署配置独立管理。
