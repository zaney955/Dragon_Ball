# 旧版规则整合与修正

日期：2026-10-10。本轮在当前未提交更新之上修正实际仍在生效的旧判断，保留已有血条、喷火、观战与地图工作。

## 已处理的问题

| 旧逻辑                            | 实际影响                                                                     | 当前规则                                                                                                                     |
| --------------------------------- | ---------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| 命中取消只检查技能是否有30气      | 高消耗、冷却中、当前形态不可用的技能占住取消选择，后面的合法连招不能执行     | 取消、实际发动、AI和界面使用当前技能可用条件；不可用的选择不会阻断后续合法取消                                               |
| 狼牙终掌绕过可用条件              | 追加提示与冷却/费用判断不一致，受击时直接调用也能重启攻击                    | 免费终掌进入统一可用条件；零气可追加，受击时拒绝                                                                             |
| AI仍按旧四角色与轻击路线选招      | 重击不衔接，旧技能条件与现行角色能力不符；后加技能策略会覆盖脱身、拆投与确反 | 按实际取消表衔接轻重击；按技能类型、距离、资源、冷却和形态选技能，保留已有行动优先级；念力控制允许近距离使用，退避只应对威胁 |
| AI世界方向的down被当作玩家后退键  | 向正Z方向追敌时，追击误变成后空翻                                            | 玩家方向派生与AI世界移动分开判断，玩家后退爆冲保留                                                                           |
| 飞行由原版、V2和少年层三次决定    | 可飞行角色与骨架实现耦合，悟空/天津饭/比克时长与指南不同                     | 单一飞行角色配置，四角色最多持续升高2秒；保留各自耗能与高度，统一起落处理                                                    |
| V2控制招命中后直接取消成远程      | 绕过少年招式取消表与确认规则                                                 | 旧捷径只适用于兼容招式，少年招式遵守其实际取消表                                                                             |
| 带anatomy的角色提前设置stageFired | 新版大招有效期进入前被标记完成，跳过共用场景破坏阶段                         | 少年大招进入共用释放阶段，场景冲击只发生一次                                                                                 |
| 飞刃将目标坐标原地减去自身坐标    | 距离判断读到方向向量，在离原点较远处不能正常回收；低帧率还会越过回收半径     | 保留目标坐标，按真实距离和本步位移判断回收，保留bladeReturn事件                                                              |
| 投射物使用固定16×10米销毁范围     | 扩大地图后，远处区域的投射物刚生成就消失                                     | 读取当前地图边界，加上原有出界余量；射程和生命期继续限制投射物                                                               |
| 训练霸体提示只读取旧armor字段     | 新版持续霸体与一次轻击保护不显示，窗口时序错误                               | 同时识别superArmor与limitedArmor，按实际有效期显示保护类型                                                                   |
| V2碰撞测试沿用上一场的随机种子    | 天津饭3%自动残像受其他AI测试随机调用次数影响，碰撞断言偶发失败               | 每个独立碰撞场景重置确定性种子，概率能力保留专门规则测试                                                                     |

皮拉夫的武装切换另有旧距离判断：AI近身时会反复切换，可能将喷火切回导弹并浪费30能量。现在近身选择喷火、远处选择导弹，已有武装适合距离时不切换；近远切换之间保留距离间隔，避免在临界位置来回切换。
