# 天神殿地图实现与验收

验收日期：2026-10-10。本地生产构建、macOS Chrome / Metal WebGL；联机使用真实本地 Workers + Durable Objects 服务。未部署线上。

## 实现

新增第四张地图 `kami`，名称「天神殿」。逻辑边界沿用 `{ x: 13.5, z: 6 }`，浮空平台半径 28 米。建筑、花坛、柏树与栏柱位于战斗区之外，并为角色后方的越肩镜头留出空间。

独立模块 `src/world/kami.js` 使用旋转体、曲面肋线、挤出拱券、石砖裁切与可复用建筑构件生成场景：

- 完整圆形平台、分层檐口、连续拱纹、侧面拱窗与浮空底座；石砖按圆形边界裁切，并带细微纹理与五种色差。
- 金色同心圆、十二瓣太阳花纹章；中央双层金顶、拱廊窗洞、带凹槽的立柱、双柱门廊、浮雕檐带、台阶及红毯。
- 对称的小型穹顶殿、高塔与柏树花坛；远景有 7 座真实三维浮岛，每座带神殿、金顶与树木。
- 三层云海，共 1,350 个实例；缓慢转动，采用柔和 Toon 明暗。天空是具有顶点色渐变的三维球壳。

沿用原 `MeshToonMaterial`、场景光照与资源管理。主殿、园林、平台和浮岛分别按材质合并，保留索引。远景构件降低分段数，云海共享几何与材质，不参与阴影和镜头射线检测。晴日、暖夕与满月夜均更新天空、云层、空气透视与环境反射光。

破坏系统复用现有伤害、碎石、扬尘和裂痕逻辑。29 块战斗区石砖保留独立破坏状态；16 处外围栏柱金饰可被投射物击碎。主殿与平台主体保持完整。地图采用既有仙豆刷新与回血规则。

额外修复实例缓冲释放：场景释放时对 `InstancedMesh` 调用 `dispose()`，随后由原资源管理器释放去重后的几何、材质和纹理。新地图光照回调不参与战斗状态序列化，已实测完整战斗存档经 JSON 往返后可恢复天神殿。

## 测试结果

- `npm run build`：通过；保留现有大于 500 kB 的打包提示。
- `npm run test:unit`：63 / 63 通过，其中天神殿专项 4 / 4。
- `npm run lint`：通过。
- `npm run architecture:check`：通过，80 个模块接口与源码一致。
- `npm run format:check`：最后一次全局检查提示 `src/online/lobby-ui.js`、`src/online/session.js`、`tests/e2e/completion-scenes.spec.js`、`tests/e2e/online.spec.js`。这些文件正在被其他工作继续修改；天神殿修改文件此前已单独格式化检查通过。
- `PLAYWRIGHT_CHANNEL=chrome npx playwright test tests/e2e/kami.spec.js tests/e2e/game.spec.js`：25 通过，2 项按原配置跳过（完整 14×14 矩阵与离线导出）。
- 最终云层调整后的天神殿专项：4 / 4 通过。
- 天神殿联机直连与中继：各通过一次完整两端验收。真实键盘移动、充气和释放必杀；两端一致记录 2 块石砖破损、1 次仙豆刷新。

镜头验收覆盖单人、训练、双人分屏的 108 个边界与朝向组合，角色到镜头最小距离为 6.3279 米。仙豆于 25 秒刷新，拾取后实际回血并留下 1 条拾取记录。地面冲击产生石砖破损与裂痕，投射物可破坏外围金饰。

反复执行三轮四地图切换，渲染器资源数量均为 252 个几何体、10 个纹理，没有逐轮增长。首次切出地图捕获 3 个云海实例释放事件、201 次几何释放事件。图鉴可查看并关闭天神殿；桌面与 390×844 移动视口均实际运行了单人战斗。

## 渲染预算与截图

1600×1000 验收视口的侧面场景：166 次渲染调用，1,664,146 个提交三角形（包含阴影绘制），地图几何属性与索引合计 45,895,328 字节，约 43.8 MiB。该数字是几何数组大小，不是浏览器总内存；云海实例数据另占少量空间。本轮未进行跨设备帧率承诺。

原始截图与渲染指标保存在本地忽略目录 `performance/kami/`，均由游戏实际 WebGL 渲染生成：

- `panorama.png`：地图全景。
- `temple-front.png`：神殿正面、门廊与台阶。
- `temple-detail.png`：穹顶肋线、拱框、柱槽和檐口细节。
- `shoulder-combat.png`：玩家越肩战斗视角，保留实际 HUD。
- `platform-side.png`：侧面拱窗、完整浮空底座、云海与远景浮岛。
- `sunset.png`、`moon.png`：暖夕与满月夜。
- `split-screen.png`、`mobile-combat.png`：双人分屏与移动端战斗。
- `render-metrics.json`：渲染调用、三角形和几何数组大小。
