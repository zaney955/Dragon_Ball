# 玩家界面与角色说明

选角页只展示角色定位、核心操作和两项技能的耗能、冷却。完整效果、发动条件、持续时间、结束方式放在“角色玩法”；帧数、判定与连招数据放在“招式数据”。战斗界面保留透明 HUD，实时显示当前武装、技能名称、能量消耗和无法发动的原因。

首页保留标题和入口，删除角色数量、版本标语和重复的模式介绍。选角提示只写关键操作或限制，不重复列举技能。技能提醒合并进对应说明；防御详细数值折叠。触屏只显示不可用原因，相同原因合并，全部就绪时不再显示状态清单。

## 输入方式

操作指南可以切换键盘 1P / 联机、键盘本地 2P、触屏。联机客机显示自己控制的右侧角色，仍使用 1P 按键。本地双人分屏分别显示各自按键。触屏第二技能有独立按钮，无需按后退与主技能的组合键。

皮尔夫的主技能只切换武装；切换后另按远程键发射。导弹每发10能量，喷火每次12能量。牛魔王、乌龙、猫仙人没有远程攻击，其远程按钮不可用。

角色练习入口会重建自由练习，并使用克林陪练；悟空练习预设满月和25%生命。练习按实际命中、形态、实体与攻击事件推进，不以等待时间自动判定成功。防反练习提供对手出招倒计时。完成后可以重试或继续自由练习。

卡林残像步接轻击、雅木茶突爪命中后追加的短窗口已接入实际输入缓冲，避免按键在原招式收招期间丢失。伤害、能量消耗和原定窗口长度沿用角色规则。

## 维护与验证

角色解释与练习步骤位于 `src/ui/character-help.js`，技能名称、耗能和冷却直接读取最终角色数据。界面状态读取实际战斗状态。新角色必须同时补充解释、操作限制和可完成的练习步骤。

`tests/e2e/player-help.spec.js` 验证全部14位角色的练习、对应招式数据、三套输入标签、武装切换、能量不足原因和联机客机的角色绑定，并检查320px、390px、844px横屏下触控按钮的可见性、尺寸与相互重叠。

赛后建议由实际接触、收招受罚和首段转化事件生成；没有达到证据阈值时不显示。单机可直接进入对应角色对位的已有空挥惩罚或命中确认练习。联机仅显示建议，保留返回房间。结算可导出最近200回合的JSON记录；统计为当前页面内存记录，刷新后清空。胜利结算卡片限制高度并可滚动，手机台词位于卡片上方。

## 复杂动作与手机模拟

越肩镜头保留平滑转向和两次避障。近身视点按双方实际水平位置取中点，竖屏按比例放宽视野，肩位结合模型骨架身高差，减少背袭出框与牛魔王遮住矮小对手。障碍按世界尺寸、材质及显式标记收集，布尔玛动态掩体也参与，隐藏或销毁后停止阻挡。

390×844与844×390模拟覆盖牛魔王贴身饺子、雅木茶真实背袭、挑空追击落地、墙边动态掩体。逐步记录对手头部投影、触屏遮挡、身体射线遮挡与转向，并保存关键画面。实际触控轻击、太阳拳后的方向重击与正常格挡单独验证。该验收是浏览器视口/触控模拟与截图检查；不替代实体手机操作、长期性能和真人平衡试玩。
