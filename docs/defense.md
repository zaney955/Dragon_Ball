# 防御机制

防御条表示格挡耐力，上限100。生命与防御分别计算；直接受击不会消耗防御。规则集中定义在 `src/combat/defense-rules.js`，所有角色、本地双人、联机和训练共用。

## 成功格挡

长按格挡键可以防御正面攻击。下段需要下蹲格挡，上段不能用下蹲格挡；背后攻击、投技和明确不可防御的攻击仍可突破格挡。

| 攻击               | 防御消耗                           | 格挡后的生命伤害 |
| ------------------ | ---------------------------------- | ---------------- |
| 普通轻击           | 逐招设定，6至23；旧招式未指定为12  | 0                |
| 普通重击           | 逐招设定，14至35；旧招式未指定为22 | 0                |
| 近战技能、方向攻击 | 按招式设定，12至40；未指定为24     | 0                |
| 普通气弹           | 6                                  | 原伤害的10%      |
| 蓄力气弹           | 18                                 | 原伤害的10%      |
| 其他投射物         | 按招式设定，8至30                  | 原伤害的10%      |
| 必杀               | 45                                 | 原伤害的20%      |

多段招式按实际命中次数扣除。耗尽防御的那次攻击会造成正常伤害并触发破防。

## 持续举防与恢复

连续举防前0.6秒不消耗耐力，之后每秒疲劳6点。单纯疲劳最低降到20点，避免无攻击时自行破防；高防御消耗的重击可以击破这一状态，较低消耗的重击不能保证一次破防。防御原本低于20时不会被疲劳抬高。

松开格挡后至少等待0.6秒；任何实际受击会把恢复等待延长至至少1.2秒。恢复只在待机、行走、下蹲或闪身时发生，每秒24点，上限100；出招、聚气、受击、倒地和被投期间均不恢复。

防御耗尽后保持0点，破防硬直0.9秒，恢复等待1.5秒。硬直结束后可以移动、反击或撤退，但防御恢复到30点前不能格挡。持续按住格挡键不会阻止破防后的恢复，达到30点后会自动重新举防。

## 完美格挡与AI

在攻击接触前75毫秒内开始举防，可完美格挡可防御的普通近战，奖励8点防御与7点能量，并获得反击窗口。沿用0.65秒冷却，格挡硬直中不能重复触发；气弹与必杀不能完美格挡。

CPU使用同一套耐力规则。低于等于25点或破防时停止持续格挡，在观察到进攻压力时后撤；受击解围的格挡加闪身输入保留。

## 显示与同步

桌面、手机和上下分屏共用防御组件。第一行显示“防御”、状态和百分比，第二行显示完整宽度的进度；正常为紫色，低于等于25点显示危险，破防归零，破防后的恢复条标记30点解锁线。

联机仍由房主模拟，客机重放实际输入。每次权威检查包含防御数值与破防锁定标记；观战快照传输防御数值、恢复等待与锁定标记。显示状态不参与战斗判定。
